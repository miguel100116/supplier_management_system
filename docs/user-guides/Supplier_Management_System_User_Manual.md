# Supplier Management System

## Admin and Employee User Manual

**Version:** 1.0  
**Updated:** October 18, 2026  
**Audience:** System Administrators and Employees

---

## About this manual

This manual explains the approved day-to-day workflow of the Supplier Management System. It is divided into two sections:

- **Admin Manual** — partner records, documents, evaluations, analytics, reports, and users.
- **Employee Manual** — assigned evaluations, submissions, reminders, and profile information.

> **Important:** Notifications and Settings are not displayed in the left sidebar. Open Notifications from the bell in the top header. Open Settings and Sign out from the account menu in the top-right corner.

---

# Part I — Admin Manual

## 1. Admin quick start

1. Open the Supplier Management System.
2. Sign in using your authorized company account.
3. Review the Dashboard for current activity and items needing attention.
4. Use the left sidebar to open Partners, Evaluations, Analytics, Reports, or Users.
5. Use the header bell for Notifications.
6. Use the account menu for Settings and Sign out.

## 2. Admin navigation guide

| Sidebar module | Available views | Main purpose |
|---|---|---|
| Dashboard | Dashboard | Review system-wide summaries and recent activity. |
| Partners | Directory, Documents, Feedback | Maintain partners, compliance records, and partner reports. |
| Evaluations | Workspace, Archive, Import Responses | Create evaluations, review responses, monitor coverage, and manage historical records. |
| Analytics | Analytics | Analyze aggregate partner and evaluation performance. |
| Reports | Generate, Present, Export History | Build reports, prepare presentations, and review exports. |
| Users | Users | Manage accounts, roles, departments, and permissions. |

## 3. Dashboard

Use the Dashboard as the starting point for daily administration.

### What you can review

- Performance indicators and system totals.
- Recent evaluation submissions.
- Evaluation completion progress.
- Partner performance summaries.
- Current or historical data scope, when available.

### Recommended workflow

1. Check the latest evaluation activity.
2. Review any completion or compliance concerns.
3. Open the related module for detailed action.

> **Tip:** The Dashboard summarizes information. Make updates inside Partners, Evaluations, Reports, or Users.

## 4. Partners

### 4.1 Directory

Open **Partners → Directory** to manage partner records.

#### Find and review a partner

1. Select the appropriate status: Active, Expired, Incomplete Profile, or Archived.
2. Select a category when needed: Courier, Supplier, Subcontractor, or Uncategorized.
3. Enter the partner name in the search field.
4. Select a row to open its detailed record.

#### Register a partner

1. Select **Register Partner**.
2. Choose manual entry or the available upload option.
3. Enter the partner name, category, affiliation, BP code, and other required information.
4. Review the information.
5. Save the partner record.

#### Edit, classify, archive, or restore a partner

1. Open the partner record from the Directory.
2. Update the appropriate partner or branch details.
3. Assign the correct category if the partner is Uncategorized.
4. Save the changes.
5. Use Archive only when the partner should no longer appear in active workflows.

> **Important:** Uncategorized partners should be reviewed before they are used in evaluations, analytics, or reports.

### 4.2 Documents

Open **Partners → Documents** to manage compliance-document records.

#### Review document status

1. Select a partner category.
2. Search by partner name or BP code.
3. Filter by document name or status.
4. Review Current, Expiring Soon, Expired, Missing, and For Update records.
5. Select a document cell to view its details.

#### Renew a document

1. Locate the correct partner and branch.
2. Select the document.
3. Choose the renewal action.
4. Enter the new expiry date.
5. Review the partner, branch, and document information.
6. Confirm the renewal.

> **Important:** Always verify the BP code and branch before changing a compliance record.

### 4.3 Feedback

Open **Partners → Feedback** to review completed evaluation results and prepare partner reports.

#### Send a partner report

1. Select the completed evaluation.
2. Select the intended partner.
3. Review the score, reporting period, graphs, and comments.
4. Choose the comments that should appear in the report.
5. Verify the recipient and copied email addresses.
6. Preview the report.
7. Send or queue the report.

#### Bulk sending

1. Choose the completed evaluation.
2. Review all eligible partners.
3. Resolve any missing recipients or incomplete results.
4. Review the generated reports.
5. Confirm the bulk-send operation.

> **Before sending:** Confirm the partner, period covered, recipient email, score, and included comments.

## 5. Evaluations

### 5.1 Workspace

Open **Evaluations → Workspace**. The Workspace contains Forms, Responses, Coverage, and Category Labels.

#### Forms — create an evaluation

1. Open the **Forms** tab.
2. Select **Create Form**.
3. Enter the evaluation title and description.
4. Select Courier, Supplier, or Subcontractor.
5. Add and organize the questions.
6. Configure the deadline and form status.
7. Select the departments and roles that can access it.
8. Select the partners covered by the evaluation.
9. Review the form.
10. Save or publish it.

#### Forms — modify an evaluation

1. Locate the evaluation form.
2. Select **Modify**.
3. Update its status, deadline, access, or assigned partners.
4. Review the changes.
5. Save the evaluation.

#### Responses

1. Open the **Responses** tab.
2. Select an evaluation.
3. Search or filter the submission list.
4. Open a submission to inspect its answers.
5. Export all or filtered responses when required.

#### Coverage

Use the **Coverage** tab to identify:

- Partners already evaluated.
- Partners still awaiting evaluation.
- Completion totals and outstanding work.
- Gaps in the current evaluation period.

#### Category Labels

Use **Category Labels** to change the labels displayed for scoring categories.

> **Note:** Changing a displayed label does not rename the underlying database or scoring fields.

### 5.2 Archive

Open **Evaluations → Archive** to review historical records.

You can:

- Review archived forms, responses, and partners.
- Search and filter archived records.
- Restore eligible records.
- Export archived responses when permitted.

Before restoring an evaluation, review its deadline, access settings, and assigned partners.

### 5.3 Import Responses

Open **Evaluations → Import Responses** to import an approved workbook.

1. Select the source workbook.
2. Allow the system to inspect the available worksheets.
3. Review the detected Courier, Supplier, and Subcontractor records.
4. Resolve unmatched or incorrectly classified partner names.
5. Review validation warnings and rejected rows.
6. Confirm the import.
7. Verify the imported results in Responses and Analytics.

> **Do not continue** while unresolved partner mappings or blocking validation errors remain.

## 6. Analytics

Open **Analytics** to review aggregate performance.

### Suggested analysis flow

1. Select the evaluation category.
2. Select the appropriate data scope and period.
3. Apply the necessary filters.
4. Review overall performance and trends.
5. Compare partners.
6. Review rankings and question-level results.
7. Record any high-risk or low-performing areas for follow-up.

Use **Evaluations → Responses** when individual submissions must be inspected.

## 7. Reports

### 7.1 Generate

Open **Reports → Generate** to create:

- Summary Report
- Partners Report
- Question Report
- Executive Summary
- Raw Data Export

#### General report workflow

1. Choose the report type.
2. Select the required category, partner, period, or questions.
3. Configure the available report options.
4. Review the preview.
5. Confirm that the values and labels are correct.
6. Export using an available format.

### 7.2 Present

Open **Reports → Present** to prepare a presentation.

1. Choose the information and categories to include.
2. Select the date range or reporting period.
3. Enter the presentation title and available notes.
4. Generate the presentation.
5. Review every slide.
6. Export as PDF or PowerPoint.

### 7.3 Export History

Open **Reports → Export History** to review recorded report exports and their available audit details.

## 8. Users

Open **Users** to manage accounts and access.

### Add an account

1. Select **Add Account**.
2. Enter the employee’s authorized company email.
3. Select the system role, designation, and department.
4. Review the automatically assigned access.
5. Apply any approved custom permissions.
6. Save the account.

### Edit access

1. Locate the account.
2. Open its edit action.
3. Review the role, designation, department, modules, and evaluation categories.
4. Apply the approved changes.
5. Save the account.

### Department access

Use **Department Access** to define the maximum access allowed for members of a department.

> **Security rule:** Grant only the access required for the employee’s responsibilities. Department access can limit an individual account even when it has custom permissions.

## 9. Notifications, Settings, and Sign out

### Notifications

Select the bell in the top header to review evaluation activity and document alerts. You can mark notifications as read and open the full notification view.

### Settings

1. Open the account menu in the top-right corner.
2. Select **Settings**.
3. Update the available appearance, notification, or administrative preferences.

### Sign out

1. Open the account menu.
2. Select **Sign out**.
3. Confirm when requested.

# Part II — Employee Manual

## 10. Employee quick start

1. Sign in using your authorized company account.
2. Review Home for pending activity.
3. Open Assigned Evaluations.
4. Complete and submit the required evaluation.
5. Review completed work under My Submissions.
6. Use the header bell for reminders.
7. Use the account menu for Settings and Sign out.

## 11. Employee navigation guide

| Sidebar module | Main purpose |
|---|---|
| Home | Review your evaluation activity and reminders. |
| Assigned Evaluations | Open and complete evaluations assigned to you. |
| My Submissions | Review your submitted evaluations. |
| Profile | Review your account, designation, department, and access information. |

## 12. Home

Home may display:

- Available evaluations.
- Completed evaluations.
- Pending requirements.
- Recent submissions.
- Deadline reminders.

Open **Assigned Evaluations** when you are ready to answer a form.

## 13. Assigned Evaluations

### Start an evaluation

1. Open **Assigned Evaluations**.
2. Select the evaluation form to answer.
3. Select the partner you are evaluating.
4. Complete the respondent information.
5. Confirm your department and respondent type.
6. Select **Proceed to Form Questions**.

Only evaluations and partners assigned to your access scope will be available.

### Answer the evaluation

1. Read each question carefully.
2. Select the rating that best represents the partner’s performance.
3. Use N/A only when the question genuinely does not apply.
4. Add a clear comment when explanation is needed.
5. Review the partner and evaluation details.
6. Select **Submit Evaluation**.

After submission, wait for the **Submission Successful** confirmation before leaving the page.

### Save unfinished work

If you leave an evaluation after entering answers, the system may offer to save your progress as a draft. Save the draft when you plan to continue later.

> **Do not submit incomplete answers** simply to preserve progress.

## 14. My Submissions

Open **My Submissions** to:

- Review previously submitted evaluations.
- Search by partner or evaluation type.
- Check submission dates.
- Return to Assigned Evaluations when more work is required.

Employees only see submissions allowed by their account and data scope.

## 15. Profile

Open **Profile** to review:

- Company email address.
- System role.
- Designation.
- Department.
- Available access information.

Contact an administrator if any information is incorrect.

## 16. Employee reminders, Settings, and Sign out

### Reminders

Select the bell in the top header to review pending evaluations and deadline reminders. You can mark reminders as read or open the complete reminder list.

### Settings

Open the account menu and select **Settings** to manage the available preferences.

### Sign out

1. Open the account menu.
2. Select **Sign out**.
3. Confirm when requested.

# Help and good practices

## If you cannot see a module or evaluation

1. Confirm that you are signed in with the correct company email.
2. Refresh the page once.
3. Confirm that the evaluation is published and within its active period.
4. Ask an administrator to verify your role, department, and permissions.

## If data appears incorrect

1. Do not create duplicate partner or evaluation records.
2. Record the affected partner, evaluation, and date.
3. Inform the administrator responsible for the module.
4. Recheck the record after the administrator confirms the correction.

## General good practices

- Verify the selected partner before editing documents or submitting an evaluation.
- Review recipients before sending partner reports.
- Resolve import warnings before committing data.
- Use comments to explain unusual ratings.
- Sign out when using a shared computer.
